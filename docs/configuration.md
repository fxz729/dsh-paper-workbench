# 配置说明

[返回首页](<../README.md>) · [使用指南](<usage.md>)

本插件面向 DeepSeek Harness `0.2.2-rc.1`、Node.js `>=24.9.0`。Desktop 与普通 Web profile 各自加载插件与配置，请在实际使用的 profile 中设置，并仅启用一份文献插件。

## 数据目录与备份

文献根目录解析顺序：

1. 插件 `dataDir` 配置。
2. 环境变量 `DSH_PAPER_READER_DATA`。
3. 默认 `~/.dsh-paper-reader/data`。

兼容变量名与默认目录沿用上游。库内包含 PDF、转录／学习／批注／墨迹旁文件、稳定身份索引、元数据、队列与事务记录。**迁移时复制完整根目录，包括隐藏文件与回收区**，不要只移动 PDF。

端点配置与文献分开保存：`$DSH_HOME/.dsh-paper-reader/`，未设置 `DSH_HOME` 时位于 `~/.dsh/.dsh-paper-reader/`。请把该目录视为敏感配置目录；读接口仅展示密钥掩码，配置文件本身仍需妥善保管。

## AI 聊天与 API 端点

### DSH 聊天

伴读使用 DSH 原生会话当前选择的 provider、模型与权限策略。插件的翻译端点不替代聊天 provider；配置聊天模型应在 DSH 的模型／凭据界面完成。

### 翻译、摘要与命名

在 DSH 的“设置 → 论文伴读 → 翻译端点”中配置 OpenAI 兼容 API；论文摘要／命名生成也复用这里的同一端点：

- `baseUrl`：服务商给出的兼容 API 基址。
- `apiKey`：你自己的凭据。
- `model`：该端点支持的模型标识。

翻译设置保存到独立的 `translate.json`；完整的本地设置优先于部署 profile 的 `translate` 默认值。摘要／命名复用该翻译端点的 URL、key 和模型，由独立任务与授权流程管理；DSH 聊天 provider 仍单独配置。

设置面板的“测试／保存”可能进行短小的真实端点请求；这类请求也可能计费。勿把测试按钮当作纯本地语法检查。配置完成后，先用一篇可公开的短文档检查费用和结果，再决定批量处理。

整篇翻译首次使用会按运行流程准备 BabelDOC、Python 环境及相关资源，可能涉及下载。网络受限时检查下载和端点错误提示；密钥不应粘贴进公开日志。

## 自动功能

| 自动功能 | 默认值 | 范围与历史行为 |
| --- | --- | --- |
| 自动摘要 | 关闭 | 全局；对启用后符合资格的新文献生效，覆盖未来子库，不回填已有文献 |
| 自动命名 | 关闭 | 全局；对启用后符合资格的新文献生效，实际物理改名 |
| 全局自动翻译 | 关闭 | 所有当前及未来库的新英文文献，不回填历史 |
| 按库自动翻译 | 关闭 | 精确 `collectionId`；父库授权不自动扩到子库 |

摘要／命名开关在文献详情界面；翻译开关在批量翻译页。模型使用 `library_manage.set_automation` 管理的是摘要／命名，不包含翻译策略或任意系统配置。

界面上明确标注费用的生成按钮与自动开关承载用户授权；模型工具调用则通过宿主确认与执行令牌核验。`confirmCosts: true` 仍须匹配宿主提供的授权凭证。

关闭自动翻译停止后续新增入队，已有队列继续受“暂停／继续”控制。摘要／命名的关闭、重启恢复和未知请求状态按其任务提示处理；请求发送后如遇网络中断，先查任务，再决定是否显式重试。

## 可选 OCR：MinerU

默认 `mineru.mode` 为 `off`。文本型 PDF 优先通过本地 PDF.js 文本层转录；扫描件可按需要配置：

- `local`：本机或受信网络上的 MinerU 服务。
- `cloud`：MinerU 云 API；文献内容会交给服务提供方处理。

本地／云端模式有各自 URL、凭据与超时设置，配置保存在 `mineru.json`。部署方还可使用 `MINERU_API_KEY` 和 `DSH_MINERU_LOCAL_URL` 作为相应配置来源；本地设置、profile 与环境的优先级由当前配置模块逐字段解析。

敏感文献建议先确认本地文本层是否足够，再决定是否使用外部 OCR；云端服务的计费与数据条款以提供方为准。

## 可选检索增强

- **Embedding**：配置兼容 embedding 服务的 `baseUrl`、`apiKey`、`model`；未配齐时关闭。配置保存在 `embed.json`。
- **重排**：可选 TypeSafe 服务；凭据与配置保存在 `typesafe.json`。

普通关键词检索可在未启用这些增强时使用。启用增强后，查询与文献片段会按相应服务请求流程发送，费用由服务商计量。

## 常见排查

| 现象 | 检查路径 |
| --- | --- |
| 插件重复注册、路由冲突 | 目标 profile 是否同时启用了上游与本插件 |
| 配置已改但实际无变化 | 确认修改的是 Desktop 或 Web 正在使用的 profile；必要时完整重开宿主 |
| 自动开关不可用 | 读取错误提示；核对当前后端版本、索引与任务状态，保留损坏状态文件 |
| 批量页仍显示待确认 | 检查源 PDF、有效译本与未知请求，不以重命名文件绕过健康校验 |
| 生成摘要失败 | 端点、模型支持、请求状态和摘要版本；未知结果先查询，不自动重发 |
| 墨迹无法启用或保存 | tldraw 许可、旁文件权限、版本冲突及恢复草稿 |
| 宿主升级后接口变化 | 本版精确针对 `0.2.2-rc.1`；先在副本验证，并查发布验证记录 |
