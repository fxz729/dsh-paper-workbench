# 发布基线与来源

DSH Paper Workbench 1.0.0 基于 GGboya/dsh-paper-reader 1.6.1。应用代码保留原作者 MIT 许可与署名，新增文献管理、稳定身份、目录导入、元数据与摘要任务、自动处理、旁文件墨迹、同步恢复和独立侧栏阅读等增强。

本仓库将当前维护的 JavaScript 核心保存在 `src/`，将可编辑的墨迹 JSX/CSS 保存在 `src/ink/`，构建后的分发入口在 `dist/`。`dist/` 和浏览器 bundle 随 Git 发行提交，DSH 的固定 Git commit 安装无需执行开发构建。维护者执行 `npm run build` 重新生成产物。

发行版采用 Node.js 24.9.0 或以上、DSH 0.2.2-rc.1 的保守兼容声明。发布说明将分别列出自动测试、本地安装包检查和隔离浏览器演示的证据范围。

`tldraw` SDK 自身遵循原厂许可，生产手写需要使用者自行取得合适许可；本仓库包含原文许可并保留 SDK 许可与水印机制。无个人许可证、API 凭据、用户文献、墨迹、聊天历史或开发机部署备份随发行包分发。
