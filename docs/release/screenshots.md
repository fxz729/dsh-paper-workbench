# 文档截图规范

本目录中的 PNG 来自 `npm run test:browser` 的独立演示环境。演示直接加载仓库生产组件和页面、实际 Host 路由及本地文献 runtime/service，使用自产样例 PDF 与虚构记录。宿主会话控制器和模型响应使用测试替身，所有外部网络请求被拦截。

截图用于展示文献树、右键操作、PDF 阅读、摘要与库备注、批量翻译界面。图中的文献、摘要与示例会话内容不取自用户资料库，也不作为真实模型输出或完整 DSH Desktop 验收证据。

手写墨迹保留生产许可校验；演示环境未使用任何私人 tldraw 许可证。实际测试步骤、通过情况和资源清理记录以发布验证说明为准。
