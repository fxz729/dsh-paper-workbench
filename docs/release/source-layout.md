# 源码与文档目录

- `src/*.js`：可维护的 JavaScript 业务源码；`dist/*.js` 是构建复制的分发入口。
- `src/ink/`：手写墨迹的 React/JSX、模型、样式与本地资源映射。
- `lib/client.js`：通过 DSH 客户端模块加载器注册的生产界面扩展。
- `reader/`：生产 PDF 阅读、批量翻译、文献详情页面与静态资源。
- `runtime/`：随包分发的可选 Python 驱动；用户配置与许可证不放入源码包。
- `tests/`：临时目录中的业务测试、SDK 合约替身和隔离浏览器演示。
- `scripts/`：构建、打包、包内容检查、干净安装与索引生成。
- `licenses/`：随应用分发的第三方许可和构建生成的依赖通知。
- `marketplace/`：固定 commit 的 DSH format-1 自定义索引及社区提交材料。

发布包仅分发运行所需代码与资源；完整维护源码、测试、文档和截图通过 GitHub 仓库提供。
