# DSH Paper Workbench 1.0.0

首个独立分发版本，基于 `dsh-paper-reader` 1.6.1 的增强工作台。

- 文献管理工具：嵌套子库、库备注、保留源文件的 PDF 非覆盖导入、稳定 ID、摘要及书目信息管理。
- 文献界面：文件夹导入预览、右键操作、摘要详情、跨库批量翻译、按库与全局新增自动处理。
- 阅读与对话：三栏文献工作台、普通工作区独立右侧伴读、选文提问、页码与原文定位。
- 笔迹与注释：独立语言变体的旁文件墨迹、并发保存保护、草稿恢复与导出；生产手写需自备 tldraw 许可。
- 同步及启动：成功重连不再误报失败，按 PDF 缩放限制墨迹纹理生成范围，按需初始化空白阅读页。
- 分发：携带预构建产物的插件压缩包、SHA-256 校验和、固定 commit 的 DSH 自定义插件索引。

适用环境：DSH `0.2.2-rc.1`、Node.js `24.9.0` 或以上。桌面端通过“插件 → 添加插件”输入 Release 中 `.tgz` 的完整下载 URL，安装后启用并完全退出重开 DSH。

本版本的具体检查结果见仓库发布验证说明。模型、翻译与 OCR 服务由使用者配置；摘要和翻译按服务端收费。自动处理默认关闭，只处理开启后符合条件的新增文献。
