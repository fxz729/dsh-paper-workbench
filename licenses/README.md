# Third-party license sources

- `tldraw-LICENSE.md`: <https://raw.githubusercontent.com/tldraw/tldraw/v5.6.0/LICENSE.md> (complete versioned SDK license).
- `IBMPlex-OFL.txt`: <https://raw.githubusercontent.com/IBM/plex/master/LICENSE.txt> (SIL OFL 1.1 and IBM copyright; line endings normalized).
- `ShantellSans-OFL.txt`: <https://raw.githubusercontent.com/google/fonts/main/ofl/shantellsans/OFL.txt> (SIL OFL 1.1 and Shantell Sans copyright).
- `pdfjs-LICENSE`: copied from the pinned `pdfjs-dist@6.4.299` package; the bundled PDF.js browser resources retain the same Apache-2.0 terms and original headers.
- `pdfjs-NOTICE`: project attribution for PDF.js; this file is not presented as an upstream NOTICE document.
- `bundled-dependencies.txt`: generated by `scripts/build.mjs` from the packages actually referenced in esbuild's production metafile.
- `upstream/react-remove-scroll-bar.LICENSE`: <https://raw.githubusercontent.com/theKashey/react-remove-scroll-bar/master/LICENSE>; the pinned npm package declares MIT but omits the license text, so the upstream license is supplied here.

The build is local and makes no network requests to obtain license files. When updating pinned dependencies, review their license changes and update this directory before publication.
